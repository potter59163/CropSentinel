## 1. ขอบเขต — เครื่องมือนี้คืออะไร และ**ไม่ใช่**อะไร

**เป็น** เครื่องมือช่วยตัดสินใจ (decision support) สำหรับ**ตั้งต้นการสนทนา**ระหว่างเกษตรกรกับเจ้าหน้าที่
ว่าแปลงหนึ่งพอจะปลูกอะไรได้บ้าง และแต่ละทางเลือกมีหน้าตาทางการเงินอย่างไร**ภายใต้สมมติฐานที่ระบุไว้**

**ไม่ใช่**:

- **ไม่ใช่การรับประกันรายได้** ตัวเลขทุกตัวเป็นค่าประมาณจากราคาและผลผลิตอ้างอิง ไม่ใช่สิ่งที่แปลงนี้จะทำได้จริง
- **ไม่ใช่คำแนะนำการลงทุนหรือคำแนะนำทางการเงิน**
- **ไม่ใช่การยืนยันสิทธิ์ที่ดิน** ชั้นข้อมูลเขตป่าเป็นการประมาณจากขอบเขตราชการที่เผยแพร่ ต้องตรวจกับเจ้าหน้าที่ป่าไม้/เกษตรอำเภอเสมอ
- **ไม่ใช่ผลตรวจดินของแปลงจริง** ใช้การซ้อนชั้นข้อมูลเชิงพื้นที่ ไม่ใช่การเก็บตัวอย่างดินไปแล็บ
- **ไม่ใช่คาร์บอนเครดิต** และตั้งใจไม่แสดงตัวเลขคาร์บอน — เหตุผลอยู่ในหน้า "วิธีการ" ของแอปและใน §7.6

> **ก่อนลงทุนจริง** ต้องตรวจสอบ 3 อย่างในพื้นที่: (1) ราคารับซื้อจริงจากพ่อค้าในพื้นที่
> (2) สิทธิ์ที่ดินกับเจ้าหน้าที่ (3) แหล่งต้นกล้าและคำแนะนำจากเกษตรอำเภอ
> ตัวเลขในแอปใช้ตั้งต้นการคุย ไม่ใช่ใช้แทนสามข้อนี้

ความสูงของแปลงจึงถูกใช้เป็นตัวแยกเพิ่ม แต่ไม่ได้ทดแทนสถานีตรวจอากาศในพื้นที่

### 3.2 ข้อมูลพืช (55 ชนิด)

**ระดับการอ้างอิงแบ่งเป็น 3 ชั้น และแสดงให้เห็นในแอปทุกชนิด** (ดู [`provenance.ts`](../src/lib/provenance.ts)):

| ชั้น | จำนวน | หมายความว่า |
|---|---|---|
| **ตัวเลขราชการ** | 9 | ยืนยันชื่อได้ในชุดข้อมูล สศก. — ลำไย ลิ้นจี่ มะม่วง สับปะรด ถั่วลิสง ถั่วเขียว เงาะ ลองกอง ชาเมี่ยง |
| **อ้างอิงบางส่วน** | 4 | มีข้อมูลราชการแต่ไม่ตรงพันธุ์/พื้นที่ — กาแฟ กล้วยน้ำว้า ข้าวไร่ พริก |
| **ประมาณการ** | 42 | ไม่มีในสถิติระดับชาติเลย |

**ข้อเท็จจริงสำคัญ 3 ข้อเรื่องตัวเลขเงิน:**

1. **ราคาทั้งหมดเป็นระดับประเทศ** ทุกระเบียนราคาของ สศก. มี `province_code = TH00` ชั้นรายจังหวัดมีเฉพาะบนชุดข้อมูล*ผลผลิต* ไม่มีบนราคา · ราคาที่จุดรับซื้อในหมู่บ้านมักต่ำกว่าค่าเฉลี่ยประเทศ
2. **ผลผลิตมีระดับจังหวัดได้** NABC AgriAPI ให้ผลผลิตระดับจังหวัด — ข้าวโพดน่าน ~693 กก./ไร่ เทียบค่าเฉลี่ยประเทศ ~790 **ใช้ตัวเลขประเทศจะสูงเกินจริงราว 14%**
3. **ราคากาแฟของ สศก. เป็นโรบัสต้า** พันธุ์พื้นที่ต่ำภาคใต้ แต่น่านปลูกอาราบิก้าบนที่สูง — คลาดเคลื่อนเชิงเศรษฐกิจจริง กาแฟจึงไม่ถูกจัดเป็นชั้น "ราชการ"

> **กับดักการตรวจสอบ:** `www.oae.go.th` เป็น Angular SPA หลัง Imperva และคืน **HTTP 200 สำหรับทุก path รวมถึง path ที่แต่งขึ้น** การตรวจ citation ด้วย status code จะรับ URL ปลอมโดยเงียบ ๆ · ทุกการอ้างอิงในงานนี้ตรวจด้วยการเปิดหน้าและอ่านเนื้อหาจริง · และ PDF ของ สศก. อยู่บน path ที่เปลี่ยนทุกรอบเผยแพร่ **ต้องอ้างหน้า article ไม่ใช่ลิงก์ PDF**

**สถานะการอ้างอิงต่างกันมาก และนี่คือข้อจำกัดที่ต้องรู้:**

- ชนิดที่อยู่ในสถิติราชการ (ลำไย มะม่วง ข้าวโพด ยางพารา ส้ม ฯลฯ) — ราคาและผลผลิตอ้างอิงได้จาก สศก./กรมส่งเสริมการเกษตร
- ชนิดพื้นถิ่นและของป่า (มะแขว่น ชาเมี่ยง ผักหวานป่า ผักกูด ผักเชียงดา หวาย เร่ว บุก) — **ไม่อยู่ในสถิติระดับชาติ**
  ตัวเลขเป็นการประมาณจากงานวิจัย/ราคาตลาดท้องถิ่นที่หาได้ ต้องปรับตามพื้นที่จริง
- พืชบริการ 6 ชนิด (ทองหลางป่า ถั่วพร้า ถั่วฮามาต้า ถั่วลาย ถั่วคาโลโปโกเนียม หญ้าแฝก) — **ราคา = 0 โดยตั้งใจ**
  เพราะไม่มีตลาดรับซื้อ การใส่ราคาสมมติเพื่อให้เข้ากับโมเดลคือการสร้างรายได้ปลอม

## 4. แบบจำลองความเหมาะสม (suitability)

โค้ด: [`src/lib/suitability.ts`](../src/lib/suitability.ts)

มี 2 เส้นทาง และแอปบอกเสมอว่าใช้เส้นทางไหน:

### 4.1 SDM (species distribution model)

ใช้เมื่อ **(ก)** ชนิดนั้นมีโมเดลที่ฝึกไว้ **(ข)** AUC ≥ เกณฑ์ขั้นต่ำ และ **(ค)** มีข้อมูลภูมิอากาศจริง

ฝึกจากข้อมูลการพบ (occurrence) + ตัวแปร bioclim/ดิน · รายละเอียดการฝึก การตรวจสอบไขว้แบบ spatial-block
และ **AUC ที่วัดได้จริงรายชนิด** อยู่ใน [`ml/MODEL-FINDINGS.md`](../ml/MODEL-FINDINGS.md)

> **ข้อความที่ต้องพูดตรง ๆ:** การตรวจสอบพบว่า **~90% ของความสามารถในการทำนายของโมเดลมาจากภูมิศาสตร์
> (ตำแหน่งในระยะ ~200 กม.) ไม่ใช่จากภูมิอากาศหรือดินของแปลง** และค่า AUC ที่ซื่อสัตย์อยู่ที่ราว **0.72**
> ไม่ใช่ 0.84 ที่เคยรายงาน · โมเดลนี้จึงแยกได้ว่า "แถบนี้ปลูกได้ไหม" ได้ดีกว่าแยกว่า "แปลงนี้ดีกว่าแปลงข้างๆ ไหม"

### 4.2 Envelope (ช่วงความสูงตามตำรา)

ใช้เมื่อไม่มี SDM — ซึ่งคือ **34 จาก 55 ชนิด**

```
envelope(พืช, ความสูง):
  ถ้าความสูงอยู่ในช่วง [elevMin, elevMax]:
      offCentre = |ความสูง − กึ่งกลางช่วง| ÷ (ครึ่งความกว้างช่วง)     # 0 ที่กลาง, 1 ที่ขอบ
      return clamp(1 − 0.18 × offCentre², 0.82, 1)
  มิฉะนั้น:
      d = ระยะที่หลุดออกจากช่วง (เมตร)
      return clamp(1 − d ÷ 450, 0.05, 1)

คะแนนสุดท้าย = envelope × ENVELOPE_CEILING        (ENVELOPE_CEILING = 0.72)
```

**ทำไมต้องมีเพดาน 0.72:** การอยู่ในช่วงความสูงที่ตำราระบุเป็นหลักฐาน**อ่อนกว่า**โมเดลที่ฝึกจากข้อมูลจริงมาก
ถ้าไม่ใส่เพดาน เวลาเน็ตล่มแล้วดึงภูมิอากาศไม่ได้ ทุกชนิดจะได้คะแนนเต็ม 1.0 และแผนจะดู**กำไรมากกว่าเดิม 50–95%**
เพราะ suitability ถูกคูณเข้าไปในรายได้โดยตรง — เกษตรกรต้องไม่เคยได้เห็นแผนที่สวยขึ้นเพราะเน็ตล่ม

**ทำไมเป็นตัวคูณไม่ใช่ตัวตัด:** เดิมใช้ `Math.min(envelope, 0.72)` ซึ่งทำให้ทุกชนิดที่อยู่ในช่วงได้ **0.720 เท่ากันหมด**
พอฐานข้อมูลโตเป็น 55 ชนิดโดย 34 ชนิดไม่มี SDM สัญญาณแยกแยะหายไปทั้งหมด และการจัดอันดับตกไปอยู่กับลำดับที่ประกาศในไฟล์

## 5. สูตรคำนวณเศรษฐศาสตร์

> ทุกสูตรในหัวข้อนี้คัดจาก [`src/lib/engine.ts`](../src/lib/engine.ts) โดยตรง
> ตัวเลขตัวอย่างคำนวณจากโค้ดจริง ไม่ได้เขียนด้วยมือ

### 5.1 การแบ่งพื้นที่ต่อชนิด

```
LAYER_SHARE = { เรือนยอด: 0.5, ชั้นรอง: 0.3, คลุมดิน: 0.4, หัวใต้ดิน: 0.4 }
shareRai(พืช) = ขนาดแปลง × LAYER_SHARE[ชั้น] ÷ จำนวนชนิดในชั้นนั้น
```

**ข้อสังเกตที่ผู้ตรวจจะถามแน่นอน:** ผลรวมของ LAYER_SHARE = **1.6 หรือ 160% ของพื้นที่แปลง**
ตั้งใจให้เป็นเช่นนั้น เพราะระบบหลายชั้น**ซ้อนกันในแนวตั้ง** — พืชคลุมดินปลูก*ใต้*เรือนยอด ไม่ได้แย่งพื้นที่ราบกัน
ตัวเลขนี้จึงเป็น "พื้นที่ใช้สอยเชิงชั้น" ไม่ใช่ "พื้นที่ราบที่ถูกจอง"

**ข้อจำกัดที่ตามมา:** ค่าคงที่ชุดนี้ไม่ได้มาจากงานวิจัยระยะปลูกของไทย เป็นค่าที่ตั้งขึ้นเพื่อให้สัดส่วนสมเหตุผล
การแทนที่ด้วยระยะปลูกจริง (ต้น/ไร่) รายชนิดจากเอกสารกรมวิชาการเกษตร คืองานที่ควรทำต่อ

### 5.2 กระแสเงินสดรายชนิด รายปี

```
สำหรับปี y = 1..10:

  ramp  = 1                                                       ถ้าเป็นพืชล้มลุก
        = 0                                                       ถ้า y < yearsToYield
        = clamp((y − yearsToYield) ÷ (yearsToMature − yearsToYield), 0, 1)   มิฉะนั้น

  fade  = 1                                                       ถ้าเป็นชั้นเรือนยอด
        = clamp(1 − max(0, canopyNow − shadeTol) × 1.3, 0, 1)      ถ้าเป็นชั้นล่าง
          โดย canopyNow = clamp(y ÷ canopyMatureYears, 0, 1) × canopyShadeMature

  active  = ramp × fade

  รายได้ = yieldKgPerRai × pricePerKg × cyclesPerYear × shareRai × active × (0.4 + 0.6 × suit)

  ต้นทุน = (establishCostPerRai × [y = 1] + annualCostPerRai) × shareRai       ถ้าไม้ยืนต้น
         = (establishCostPerRai + annualCostPerRai) × shareRai                ถ้าล้มลุกและ active > 0.05

  net(y) = รายได้ − ต้นทุน
```

**พจน์ `(0.4 + 0.6 × suit)` คืออะไร:** เป็นการลดผลผลิตตามความเหมาะสมของพื้นที่
พืชที่คะแนนความเหมาะสม 0 ยังให้ผล 40% ของศักยภาพ ไม่ใช่ 0 — เพราะเกษตรกรมักดูแลชดเชยได้บางส่วน
**นี่คือค่าที่ตั้งขึ้น ไม่ได้ปรับเทียบกับข้อมูลผลผลิตจริง** และเป็นหนึ่งในข้อจำกัดหลักของโมเดล (ดู §7.2)

**พจน์ `fade` คืออะไร:** เมื่อเรือนยอดปิด พืชชั้นล่างที่ไม่ทนร่มจะให้ผลผลิตลดลง
ตัวคูณ 1.3 และรูปแบบเชิงเส้นเป็นค่าที่ตั้งขึ้นเช่นกัน

### 5.3 ตัวอย่างคำนวณจริง — ลำไย

แปลง 10 ไร่ · อ.ปัว · ความสูง 400 ม. · เกษตรกรเลือกลำไยในชั้นเรือนยอด

ค่าจากฐานข้อมูล: `yieldKgPerRai=900, pricePerKg=30, cyclesPerYear=1, yearsToYield=4,
yearsToMature=7, establishCostPerRai=8000, annualCostPerRai=4000`
ค่าที่คำนวณได้: `shareRai=2.5` (10 × 0.5 ÷ 2 ชนิดในชั้นเรือนยอด), `suit=0.460`

ตัวคูณความเหมาะสม = 0.4 + 0.6 × 0.460 = **0.676**

| ปี | ramp | รายได้ (บาท) | ต้นทุน (บาท) | net (บาท) |
|---:|---:|---:|---:|---:|
| 1 | 0.0000 | 0 | 30,000 | −30,000 |
| 2 | 0.0000 | 0 | 10,000 | −10,000 |
| 3 | 0.0000 | 0 | 10,000 | −10,000 |
| 4 | 0.0000 | 0 | 10,000 | −10,000 |
| 5 | 0.3333 | 15,210 | 10,000 | 5,210 |
| 6 | 0.6667 | 30,420 | 10,000 | 20,420 |
| 7 | 1.0000 | 45,630 | 10,000 | 35,630 |
| 8–10 | 1.0000 | 45,630 | 10,000 | 35,630 |

ตรวจสอบปีที่ 5: `900 × 30 × 1 × 2.5 × 0.3333 × 0.676 = 15,210` ✓
ต้นทุนปีที่ 1: `(8,000 + 4,000) × 2.5 = 30,000` ✓ (ปีอื่น `4,000 × 2.5 = 10,000`)

### 5.4 รวมทั้งแผน

```
net(y) รวมทุกชนิด − (ต้นทุนเปลี่ยนผ่าน ถ้า y = 1)
cumulative(y) = ผลรวมสะสม
profit10      = cumulative(10)
annualAvg     = profit10 ÷ 10
paybackYear   = ปีแรกที่ cumulative ≥ 0   (null ถ้าไม่ถึงใน 10 ปี)
```

**`annualAvg` มีข้อควรระวัง:** เป็นค่าเฉลี่ยที่รวมปีที่ยังไม่ให้ผลเข้าไปด้วย
ระบบที่มีไม้ยืนต้นจะดูรายได้เฉลี่ยต่ำทั้งที่พอโตเต็มที่แล้วรายได้สูงสม่ำเสมอ
แอปจึงแสดง**ทั้งค่าเฉลี่ยรวมและค่าตอนโตเต็มที่** (เฉลี่ย 3 ปีท้าย) เมื่อเทียบกับเป้าหมายรายได้
ดู [`src/lib/incomeGoal.ts`](../src/lib/incomeGoal.ts)

### 5.5 ต้นทุนเปลี่ยนผ่านจากพืชเดิม

โค้ด: [`src/lib/landHistory.ts`](../src/lib/landHistory.ts)

```
ต้นทุนถางพื้นที่ + ต้นทุนปรับปรุงดิน   (แยกแสดง ไม่รวมเป็นก้อนเดียว)
```

ตัวอย่าง ข้าวโพด 10 ไร่: ถาง 900 × 10 = 9,000 + ปรับดิน 1,500 × 10 = 15,000 = **24,000 บาท**

## 6. การจัดอันดับแผน

### 6.1 คะแนนรายชนิด

```
suit = clamp(SDM_หรือ_envelope × 0.62 + waterFit × 0.12 + riskFit × 0.10
             + soilFit × 0.10 + (ไม้ยืนยาว ÷ สูงสุด) × 0.06,  0, 1)
```

### 6.2 การเลือกตามเป้าหมาย

```
เห็นผลไว   = 0.30·suit + 0.32·เร็ว + 0.16·มูลค่า + 0.12·น้ำ + 0.10·ความเสี่ยง
กำไรสูงสุด = 0.24·suit + 0.48·มูลค่า + 0.10·น้ำ + 0.10·ความเสี่ยง + 0.08·ไม้ยืนยาว
สมดุล      = 0.36·suit + 0.22·มูลค่า + 0.17·น้ำ + 0.13·ความเสี่ยง + 0.12·ไม้ยืนยาว
```

**น้ำหนักเหล่านี้ตั้งขึ้นจากการตัดสินใจเชิงออกแบบ ไม่ได้ปรับเทียบจากข้อมูลผลลัพธ์จริงของเกษตรกร** (ดู §7.1)

### 6.3 กฎเชิงโครงสร้าง

- ชั้นเรือนยอดต้องมี **≥ 2 ชนิด**
- ชั้นเรือนยอดมีพืชรายได้ต่ำ (< 10,000 บาท/ไร่/ปี) ได้ **ไม่เกิน 1 ชนิด** — ไม้พี่เลี้ยงเป็นส่วนประกอบได้ แต่ต้องไม่ใช่ทั้งเรือนยอด
- ถ้าทั้งแผนไม่มีพืชตรึงไนโตรเจนเลย ชั้นคลุมดินจะเลือกพืชตรึงไนโตรเจนก่อน
- พืชที่ประวัติที่ดินบอกว่ายังไม่ควรลง (เช่น อะโวคาโด บนดินเสื่อมโทรม) จะถูก**ลดอันดับ ไม่ใช่ตัดทิ้ง** — เกษตรกรที่เลือกเองยังได้

## 7. ข้อจำกัดที่ทราบ

หัวข้อนี้ตั้งใจเขียนให้ยาวและตรงไปตรงมา เพราะเป็นสิ่งที่ผู้ตรวจควรได้อ่านก่อนถาม

### 7.1 น้ำหนักการให้คะแนนไม่ได้ปรับเทียบ
น้ำหนักใน §6 ทั้งหมดเป็นการตัดสินใจเชิงออกแบบ ไม่มีชุดข้อมูลผลลัพธ์จริงของเกษตรกรน่านมาปรับเทียบ
แผนที่ได้อันดับ 1 จึงหมายถึง "ดีที่สุดตามน้ำหนักชุดนี้" ไม่ใช่ "ดีที่สุดที่พิสูจน์แล้ว"

### 7.2 พจน์ผลผลิตตามความเหมาะสมไม่ได้ปรับเทียบ
`(0.4 + 0.6 × suit)` และ `fade` เป็นรูปแบบที่ตั้งขึ้น ไม่ได้มาจากการวัดผลผลิตจริงเทียบกับความเหมาะสม
เป็นแหล่งความคลาดเคลื่อนที่ใหญ่ที่สุดจุดหนึ่งของตัวเลขรายได้

### 7.3 ~90% ของความสามารถของ SDM มาจากภูมิศาสตร์
วัดแล้ว (ดู `ml/MODEL-FINDINGS.md`) โมเดลบอก "ภูมิภาคนี้ปลูกได้ไหม" ได้ดีกว่า "แปลงนี้ดีกว่าแปลงข้าง ๆ ไหม"
AUC ที่ซื่อสัตย์ ≈ 0.72

### 7.4 34 จาก 55 ชนิดไม่มี SDM
ใช้ envelope ความสูงล้วน ซึ่งไม่รู้เรื่องฝน ดิน หรือความเสี่ยงภัยพิบัติของแปลงนั้น

### 7.5 ภูมิอากาศหยาบกว่าภูมิประเทศ
NASA POWER 0.25° (~28 กม.) ในพื้นที่ที่ความสูงเปลี่ยนหลายร้อยเมตรในไม่กี่กิโลเมตร

### 7.6 ไม่มีตัวเลขคาร์บอน
ตั้งใจเอาออก — T-VER ต้อง ≥10 ไร่ ต้องมีเอกสารสิทธิ์ (ที่ดิน คทช. จำนวนมากในน่านไม่มี)
ค่าใช้จ่ายปีแรก ~50,000–75,000 บาท เทียบกับรายได้คาร์บอนราว 460 บาท/ปี ที่ 10 ไร่
และ RECOFTC ประกาศเองว่าไม่ทำคาร์บอนเครดิตเพราะแพงเกินไปและผลักเกษตรกรรายย่อยออก

### 7.7 ราคาเป็นค่าคงที่ ไม่ใช่ราคาสด
ยังไม่มีการเชื่อมฟีดราคาอัตโนมัติ ราคาในระบบต้องอัปเดตด้วยมือ
**เกษตรกรควรใส่ราคาที่ตัวเองขายได้จริงทับเสมอ** — แอปมีช่องให้ใส่ทั้งราคาและต้นทุน

### 7.8 ไม่มีข้อมูลย้อนกลับจากแปลงจริง
ยังไม่เคยมีการเก็บผลลัพธ์จริงจากแปลงที่ใช้แผนนี้มาเทียบกับที่ทำนายไว้
จนกว่าจะมี ความแม่นยำของตัวเลขรายได้ยัง**ไม่เคยถูกทดสอบ**

### 7.9 ระยะปลูกยังเป็นสัดส่วน ไม่ใช่ต้น/ไร่จริง
§5.1 ใช้สัดส่วนพื้นที่ ไม่ได้ใช้ระยะปลูกจริงรายชนิด

### 7.10 ชั้นข้อมูลกฎหมายเป็นการประมาณ
ขอบเขตป่าสงวนที่ใช้มาจากชั้นข้อมูลที่เผยแพร่ ซึ่งเป็นค่าประมาณของกรมป่าไม้ ไม่ใช่การรังวัด

## 11. ผังปลูกและแนวกันไฟ

โค้ด: [`src/lib/layout.ts`](../src/lib/layout.ts)

### 11.1 รูปแบบ "แถบ"

ระบบไม่วาดแผนที่แปลง แต่ให้**แถบที่ทำซ้ำได้** (แถวไม้ใหญ่ 1 แถว + ช่องว่าง 1 ช่อง) เพราะแผนที่ต้องรู้รูปร่างแปลง ทิศ
และความลาดชัน ซึ่งแอปไม่ได้เก็บ — และแถบเป็นหน่วยที่คู่มือกรมป่าไม้ใช้เอง

**กฎปีที่ 6** มาจาก *รูปแบบการปลูกไม้ป่าโดยระบบวนเกษตร* (กรมป่าไม้ 2556): พืชไร่ปลูกในช่องว่างระหว่างแถว
เริ่มห่างจากแถว 50 ซม. ขยับออกปีละ 50 ซม. และ**ปีที่ 6 เปลี่ยนจากพืชชอบแดดเป็นพืชทนร่ม**
— ตำราไทยอธิบายเรื่องแสงเป็น*ปี* ไม่ใช่เปอร์เซ็นต์แสง (ไม่พบแหล่งไทยที่ให้ % แสงใต้เรือนยอดรายชนิด — เป็นข้อจำกัด)

**เกณฑ์พืชชอบแดด `shadeTol < 0.4`** · ข้อมูลมีช่องว่างตามธรรมชาติ — พืชต้องการแดดอยู่ 0.10–0.35 พืชทนร่มอยู่ 0.45+
มีเพียงตะไคร้ที่ 0.40 คั่นกลาง · เกณฑ์เดิม `< 0.35` ตัดถั่วลิสง (ค่า 0.35 พอดี) ออก จึงพลาดตัวอย่างที่ที่ประชุมยกมาเอง

### 11.2 ทิศทางแถว — แหล่งข้อมูลขัดแย้งกันจริง

| แหล่ง | บอกให้ทำ | เหตุผล |
|---|---|---|
| กรมป่าไม้ | แถวตะวันออก–ตะวันตก | รับแสงสม่ำเสมอ |
| กรมวิชาการเกษตร, กรมพัฒนาที่ดิน | แถวขวางความลาดชัน (ตามแนวระดับ) | ลดการชะล้าง |

**ระบบเลือกแนวระดับ** เพราะบนที่ลาดชันของน่าน ดินที่หายไปเอาคืนไม่ได้ และแถวตามแนวระดับคือสิ่งที่แถบหญ้าแฝกต้องการอยู่แล้ว
เอกสารนี้ระบุความขัดแย้งไว้แทนที่จะซ่อน

### 11.3 แนวกันไฟ

**8–10 เมตร ถางถึงดิน** (กรมป่าไม้, สวพส./HRDI) ทำก่อนพฤศจิกายน ฤดูไฟรุนแรงสุดราวกุมภาพันธ์

**ความกว้างที่ต้องใช้ขึ้นกับที่ข้างเคียง ไม่ใช่แปลงตัวเอง** — Wanthongchai et al. (2021) วัด**ในแปลง จ.น่าน**:

| เชื้อเพลิง | ความสูงเปลวไฟ |
|---|---|
| ตอซังข้าวโพด | 1.42 ม. |
| ป่าเบญจพรรณ | 1.34 ม. |
| ที่รกร้างบนที่สูง | 7.13 ม. |
| ไร่เหล่า 5 ปี (ลาดชัน >35%) | **12.82 ม.** |

แนว 8 เมตรเหลือเฟือสำหรับไฟจากตอซังข้าวโพด แต่**แคบกว่าเปลวไฟจากไร่เหล่าข้างเคียง**
เมื่อไม่มีความกว้างใดสู้ได้ ระบบบอกตรง ๆ ให้ไปคุยกับเจ้าของที่ข้างเคียงและผู้ใหญ่บ้าน/อบต. แทนที่จะแนะนำให้ถางกว้างขึ้น

**ไผ่ไม่ใช่แนวกันไฟ** — รายงานการจัดการไฟโดยชุมชนของ RECOFTC (2567) จัดกอไผ่เป็นเชื้อเพลิงเสี่ยงสูง
จากใบแห้งและลำแห้งที่สะสมในกอ · แอปแนะนำไผ่บ่อย จึงต้องเตือนชัดเจน

## 12. ชันโรง

โค้ด: [`src/lib/bees.ts`](../src/lib/bees.ts) · ที่มา: กรมส่งเสริมการเกษตร ข้อมูลแมลงเศรษฐกิจ

| รายการ | ค่า |
|---|---|
| ลงทุนต่อรัง (ครั้งเดียว) | 1,600 บาท |
| รายได้ต่อรังต่อปี | น้ำผึ้ง 600 + ชัน 400 + **ขายรัง 1,500** = 2,500 บาท |
| ความหนาแน่น | 4 รัง/ไร่ (สวนผสม) · 10 รัง/ไร่ เป็นของสวนเชิงเดี่ยว |
| รัศมีหาอาหาร | 300 เมตร |

**60% ของรายได้มาจากการขายรัง ไม่ใช่น้ำผึ้ง** — ไม่มีคนรับซื้อรังจะได้ 1,000 บาท/รัง/ปี ไม่ใช่ 2,500
และจุดคืนทุนยืดจากต่ำกว่า 1 ปี เป็นราว 1.6 ปี · กรมส่งเสริมการเกษตรเองระบุการตลาดรังเป็นจุดอ่อนของวงการ
แอปจึงแสดงการแยกส่วนเป็นหลัก ไม่ใช่ตัวเลขเดียว · **ตัวเลขชันโรงไม่ถูกรวมในกราฟรายได้ของแผน**

**ไม่ได้ทำ:** อัตราการเลี้ยง สูตรอาหาร การเลือกพันธุ์ โมเดลรายได้วัว/แพะ/หมู เครื่องคำนวณธาตุอาหารจากมูลสัตว์ สุขภาพสัตว์
— คนละวิชาชีพ และกรมส่งเสริมการเกษตร/กรมปศุสัตว์ดูแลอยู่แล้ว · วัวปรากฏเฉพาะในฐานะ**ข้อจำกัด**
เพราะการปล่อยวัวเลี้ยงในป่าเป็นเรื่องปกติในน่าน แปลงที่เพิ่งปลูกต้องกัน 2–3 ปีแรก

## 13. พืชเดิม

โค้ด: [`src/lib/landHistory.ts`](../src/lib/landHistory.ts)

พืชเดิมไม่ได้ให้แค่ตัวเลขต้นทุน แต่ให้**ธง** ที่ไปเปลี่ยนพืชที่แนะนำ คำเตือน และงานปีที่ 0

**ยางพารา — เดิมคำนวณกลับด้าน** เคยตั้ง 6,800 บาท/ไร่ = แพงที่สุดในตาราง แต่ความจริง กยท. จ่ายทุนปลูกแทน
(มีประเภท "ปลูกแทนด้วยไม้ยืนต้นเศรษฐกิจ" และ "เกษตรกรรมยั่งยืน" ซึ่งตรงกับแผนวนเกษตรพอดี) และขายไม้ยางได้อีก
· Neyret et al. (2020) วัดได้ว่าสวนยางบนที่ลาดชันภาคเหนือ**ชะล้างหน้าดินมากกว่าข้าวโพด**

**ค่าโค่นตอยางตั้งเป็น `null` ไม่ใช่ตัวเลข** เพราะค้นแหล่งไทยแล้วไม่พบการเผยแพร่ค่าขุดตอยางต่อไร่
แสดงเป็น "ยังประเมินไม่ได้" ไม่ใช่ 0 เพราะ 0 อ่านว่าฟรี · **ไม่ hard-code อัตราทุนปลูกแทน** เพราะเปลี่ยนทุกปีงบประมาณ

**ไม่ได้ใส่โดยตั้งใจ:** พาราควอต/ไกลโฟเซตตกค้างหลายปี (ความเชื่อที่แพร่หลายในไทยแต่ไม่มีหลักฐานรองรับ
— มี test บังคับว่าสตริงนี้ต้องไม่ปรากฏ), อะทราซีนในฐานะปัญหาหลายปี (จริงคือ 1 ฤดูฝน และเฉพาะพืชคลุมดินใบกว้างกับถั่ว),
รายชื่อไม้เบิกนำของภาคเหนือ (มีของภาคใต้ ไม่มีของเหนือ — การแต่งขึ้นจากข้อมูลใต้คือความผิดพลาดที่งานนี้ตั้งใจกำจัด)

## 14. ข้อจำกัดเพิ่มเติมจากงานรอบนี้

- **~20 ชนิดไม่มีตัวเลขเศรษฐกิจระดับชาติเลย** — มะแขว่น ชาเมี่ยง ผักหวานป่า ผักกูด ผักเชียงดา หวาย เร่ว บุก
  ทองหลางป่า อะโวคาโด แมคคาเดเมีย พืชคลุมดินตระกูลถั่ว และไม้ใช้สอยทั้งหมด ซึ่งเป็นพืชกลุ่มที่ทำให้ระบบวนเกษตรทำงานได้พอดี
- **ต้นทุนอ้างอิงของ สศก. เก่าราว 5 ปีครึ่ง** — ไฟล์ต้นทุนทุกไฟล์ลงวันที่ ธันวาคม 2563
- **ไม้ใช้สอยไม่ให้รายได้ในกรอบ 10 ปี** — สัก ยางนา ประดู่ป่า มะค่าโมง แดง รัง ตั้ง `yearsToYield` 15–30 ปี
  จึงปรากฏเป็น**ต้นทุนล้วน**ในแผน 10 ปี ถูกต้องตามความจริง แต่ทำให้แผนที่มีไม้ใช้สอยดูแย่กว่าคุณค่าระยะยาวจริง
- **แนวกันไฟคำนวณจากแปลงสี่เหลี่ยม** — พื้นที่ที่เสียไปประมาณจากเส้นรอบรูปสี่เหลี่ยมจัตุรัส บอกได้แค่ระดับขนาด
- **ชนิดของที่ดินข้างเคียงยังต้องกรอกเอง** — ความเสี่ยงไฟขึ้นกับที่ข้างเคียงมากกว่าแปลงตัวเอง แต่ยังไม่มีชั้นข้อมูลบอก
- **ไม่มีการเชื่อมฟีดราคาอัตโนมัติ** — NABC AgriAPI ใช้ได้ ไม่ต้องใช้คีย์ และมีผลผลิตระดับจังหวัด
  แต่ยังไม่ได้ต่อเข้าระบบ · ครอบคลุมราว 9 พืชเท่านั้น
