## ⬜ สิ่งที่ต้องทำเอง เรียงตามความเร่งด่วน

### 1. แก้ Root Directory ใน Vercel — ทำก่อนอย่างอื่น

โฟลเดอร์ถูกเปลี่ยนชื่อจาก `legacy-static/` เป็น `cropsentinel/` แล้ว แต่การเปลี่ยนชื่อโฟลเดอร์
**ไม่ได้เปลี่ยนค่าใน Vercel** ต้องเข้าไปแก้เอง

- เข้า Vercel → โปรเจค **crop-sentinel** → Settings → General → Root Directory
- เปลี่ยนเป็น `cropsentinel` → Save → Redeploy
- เปิด https://crop-sentinel.vercel.app/ ตรวจว่าขึ้นจริง ไม่ใช่ 404

> ถ้ากรรมการกดลิงก์ต้นแบบในฟอร์มแล้วเจอ 404 งานทั้งหมดเสียเปล่า

โปรเจค `nan-agroforestry` ไม่ต้องแตะ ชื่อโฟลเดอร์ไม่ได้เปลี่ยน

### 2. หาอาจารย์ที่ปรึกษา 1 ท่าน — เป็นช่องบังคับ

ฟอร์มมีช่อง "อาจารย์ที่ปรึกษา / ผู้ควบคุม" พร้อมชื่อ ตำแหน่ง หน่วยงาน อีเมล โทรศัพท์
และต้องมี **ลายเซ็นผู้ควบคุมทีม** ตอนส่ง ไม่นับเป็นสมาชิกในทีม

### 3. กรอกช่อง `[ ... ]` ในฟอร์ม

- อีเมลและเบอร์โทรของสมาชิกทั้ง 3 คน
- ชื่อ ระดับชั้น สถานศึกษา ของสมาชิกคนที่ 3
- ชื่อหัวหน้าทีม + Line ID
- ข้อมูลอาจารย์ที่ปรึกษา
- ลายเซ็น 2 จุด + วันที่

### 4. แนบภาพหน้าจอ 3 ภาพในฟอร์ม (ส่วนที่ 4 "พื้นที่แสดงภาพร่าง")

เปิดต้นแบบ → เมนู **ภารกิจ** แล้วจับภาพ
1. ขั้น **หลักฐาน** ตอนกดเลือกโครงการ *รังสิตเหนือ* ให้เห็น 5 อำเภอสว่างขึ้น ← ภาพสำคัญที่สุด
2. ขั้น **ตัดสินใจ** ให้เห็นตัวเลือกเหลื่อมรอบส่งน้ำ โควตา THEOS-2 และแถบเลื่อนสมมติฐาน
3. ขั้น **ผลลัพธ์** ให้เห็นตัวเลข 4 ช่องและอันดับ "1 / 55"

### 5. จัดรูปแบบฟอร์มลง .docx

- เปิด `แบบฟอร์มสมัครกิจกรรม The Geo Quest 2026.docx`
- คัดลอกเนื้อหาจาก `form-draft.md` วางตามช่องที่ตรงกัน
- ฟอนต์ **TH Sarabun PSK ขนาด 16 pt**
- ตรวจว่า **ไม่เกิน 8 หน้า A4** (ร่างประมาณ 5 หน้า markdown ตารางจะขยายตอนวาง)

### 6. ถ่ายคลิป

ทำตาม `video-script.md` — มีไทม์ไลน์ 8 ท่อน บทพากย์คำต่อคำ รายการช็อต 11 ช็อต
และเช็กลิสต์ก่อนอัด/ก่อนส่งอยู่ในไฟล์นั้นแล้ว

- บันทึกหน้าจอ **1920 × 1080 ขึ้นไป** ไฟล์ **.mp4**
- ความยาว **ไม่เกิน 3:00** (สคริปต์คำนวณไว้ที่ 172 วินาที เหลือช่องว่าง 8 วินาที)
- ใส่ซับไทยติดในคลิป เผื่อกรรมการเปิดโดยไม่มีเสียง
- อัปโหลด Google Drive หรือ YouTube แล้วตั้งเป็น **"ผู้ที่มีลิงก์เท่านั้น"**
- ทดสอบเปิดลิงก์จากโหมดไม่ระบุตัวตน ว่าเปิดได้จริง

ส่งใบสมัครและลิงก์คลิปตามช่องทางที่ผู้จัดกำหนด **ภายใน 12 สิงหาคม 2569**

## ✅ สิ่งที่ตรวจแล้วผ่าน

**ข้อมูล** ดึงจาก GISTDA ใหม่แล้วเทียบ — ยังเป็นวินเทจเดิม ตัวเลข 16 รายการตรงกันทั้งในไฟล์ฐาน
แบบฟอร์ม และสคริปต์คลิป

**เว็บ** ทั้ง 4 หน้า (M01 M02 M03 ภารกิจ) ทั้งที่ 1440px และ 360px
- ผ่าน WCAG AA ทุกจุด (0 จุดตก)
- ไม่มีตัวอักษรต่ำกว่า 12px
- ไม่มีการเลื่อนแนวนอน
- ไม่มี error ในคอนโซล
- ไม่มีคำว่า NaN บนหน้าจอ
- ไม่มีพื้นเข้มค้างจากธีมเดิม

**ความซื่อสัตย์ของเนื้อหา** ไล่ตรวจทั้งโปรเจคแล้ว ไม่เหลือข้อความที่อ้างเกินจริง
- ไม่มี "AI forecasting" (ไม่มี AI ในระบบ)
- ไม่มี "Real-time Dashboard" (ข้อมูลข้าวเป็นภาพย้อนหลัง)
- ไม่มี "พยากรณ์ราคา" (เป็นฉากทัศน์)
- ไม่มีตัวเลขความเชื่อมั่นที่ไม่ได้คำนวณ — เปลี่ยนเป็นบรรทัด "ที่มา:" ของแต่ละการแจ้งเตือน
- ค่าสมมติทุกตัว (กำลังสีข้าว ราคา) ติดป้ายบนหน้าจอและปรับได้

## หากตัวเลขเปลี่ยนก่อนส่ง

GISTDA อาจปล่อยชั้นข้อมูลข้าววินเทจใหม่ ถ้าเกิดขึ้น ตัวเลขในฟอร์มจะกลายเป็นของเก่าทันที
ให้รันคำสั่งนี้แล้วเทียบกับที่เขียนไว้ในเอกสาร

```bash
cd cropsentinel && python3 build-gistda-baseline.py
```

สคริปต์จะพิมพ์ตัวเลขหลักออกมา และจะ **หยุดทำงานทันที** ถ้าเจอค่าที่เป็นไปไม่ได้
เช่น พื้นที่นามากกว่าพื้นที่จังหวัด
